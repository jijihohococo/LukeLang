Wedge: reactive full-stack web — see STRATEGY.md (the decision record this roadmap serves).
Current track: Frontend (this document) + Backend beachhead opening
Next track: Backend deepen (BACKEND_ROADMAP.md) — unlocks full-stack reactivity
Master checklist: TaskList.md
Parked: Scripting → Mobile → Game, plus the own-the-pixels renderer (earned post-beachhead)

Reactive change model: REACTIVE.md
Ship path: PRODUCTION_WEB.md

Renderer direction (Path A): compile to DOM + CSS — the browser lays out and paints; Argus is a thin reactive patcher (dirty node → surgical DOM update) and Hanka emits flex/grid rather than computing absolute frames. Rationale in STRATEGY.md.

Order Track Goal Status

Parked ≠ cancelled: these are sequenced after the frontend proof point, picked up from a position of strength. Do not pull parked tracks into Frontend PRs unless they unblock ship.

Surface cheat sheet

raw "BEGIN ROW AT 0, 0 SIZE 600, 80 GAP 8 STACK BELOW 640"raw "SLOT BUTTON \"buy\" SIZE AUTO, 40 SAY \"Buy\" WEAR \"px-5 rounded-xl bg-indigo-600 text-white\""raw "END ROW"raw "BEGIN GRID AT 0, 100 SIZE 400, 200 COLUMNS 2 GAP 8 SCROLL"raw "SLOT TEXT \"status\" SIZE AUTO, 24 SAY \"Ready\" ANNOUNCE"raw "END GRID"raw """WHEN THE VIEWPORT IS BELOW 640 DO  SPEAK "narrow"END WHEN"""raw """WHEN THE VIEWPORT IS AT LEAST 800 WIDE DO  SPEAK "desktop"END WHEN"""raw "luke PUBLISH WEB app.luke -o dist/app --tailwind input.css"

Coexistence: Hanka owns layout (inline flex/grid/size). Tailwind WEAR owns skin (color, type, border, shadow). Tailwind layout utilities (flex, w-*) lose to inline styles on purpose.

01

One graph,
end to end.

Mainstream stacks glue three worlds together with fetch, cache invalidation, subscriptions and diffing. LukeLang keeps one dependency graph that the compiler can see — so change travels on its own.

You never fetch.

You never invalidate.

You never subscribe.

You never diff.

You declare the dependency once — and exactly 1 region paints.

02

Reads like intent.
Runs like C.

Typed Build mode, arena memory, and no garbage collector on the ship path. The same source targets a native binary or the browser. 

print("Hello from Luke Build")
let name = "Luke"
print("My name is " + name)

fn add(a: float, b: float) -> float {
  return a + b
}

print(add(21, 21))  // 42 — native code, arena memory
signal price = 100
signal quantity = 3
derived total = price * quantity

effect on total {
  print("total=" + total)
}

price = 200          // total=600, one flush
batch {
  price = 120
  quantity = 5       // still one flush
}
import std/server
import std/sqlite

let db = dbOpen("/tmp/luke_live_graph.db")
watch user from db where "id = 1"

let server = httpListen(8798)
let req = httpAccept(server)

push watch user on req for 50 beats every 50 ms
import std/js

signal user = ""
bind("name", user)
watch user from "http://127.0.0.1:8798/watch"

04

What the language believes.

  1. Write like you talk. Ship like systems. The surface stays readable; the compiler keeps the guarantees.
  2. Build is the language of record. Types, layouts and arenas are decided at compile time, not guessed at runtime.
  3. The browser is the renderer. Compile to DOM and CSS; patch surgically, never repaint the world.
  4. One beachhead. Win reactive full-stack first. Everything else is earned later.
05

Three lines to your first binary.

git clone https://github.com/lucasdmarshall/LukeLang.git
cd LukeLang/vm && make
./build/luke BUILD ../examples/build/hello.luke -o hello && ./hello
